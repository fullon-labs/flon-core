## Overview

Plugins extend the core functionality implemented in `fuwal`. For information on specific plugins, just select from the list below:

* [`http_plugin`](../../01_node/03_plugins/http_plugin/index.md)
* [`wallet_api_plugin`](wallet_api_plugin/index.md)
* [`wallet_plugin`](wallet_plugin/index.md)

[[info | Fuwal is modular]]
| Plugins add incremental functionality to `fuwal`. Unlike runtime plugins, `fuwal` plugins are built at compile-time.

## Description
Interact with local p2p network connections.

## Command

```console
Usage: fucli net SUBCOMMAND
```

## Subcommands

 - [fucli net connect](connect.md) start a new connection to a peer

 - [fucli net disconnect](disconnect.md) close an existing connection

 - [fucli net status](status.md) status of existing connection

 - [fucli net peers](peers.md) status of all existing peers

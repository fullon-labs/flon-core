## Description
Interact with local p2p network connections.

## Command

```console
Usage: focli net SUBCOMMAND
```

## Subcommands

 - [focli net connect](connect.md) start a new connection to a peer

 - [focli net disconnect](disconnect.md) close an existing connection

 - [focli net status](status.md) status of existing connection

 - [focli net peers](peers.md) status of all existing peers
